# SimOne Starter

The SimOne Starter package gives a new company a legible operating map before agents begin running work.

## Contents

- `CEO` - coordinates judgment, priorities, and approval boundaries.
- `Product Lead` - owns offer, roadmap, and delivery clarity.
- `Customer Lead` - owns discovery, trust, demand, and customer signal.
- `Cash Lead` - owns pricing, revenue, runway, and economic reality.
- `Skills Lead` - owns capability, learning, leverage, and agent/team skill development.
- `sprint-zero` - SIM Wiki-ready project for drafting the first SIM map from messy founder input.

## Operating stance

This package is intentionally simple. It should help nontechnical founders start with a coherent company system rather than a blank agent-control plane.

When the SIM Wiki plugin is enabled for the company, its managed SIM Wiki Maintainer can attach durable memory and coaching context to this Sprint Zero structure.
