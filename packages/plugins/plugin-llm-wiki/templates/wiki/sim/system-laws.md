# SIM System Laws

System laws are coaching constraints. They are not hard product rules yet; they are default warnings that help nontechnical operators avoid delegating away the parts of company-building that require judgment.

## Keep Feedback Visible

Every meaningful agent workflow should leave behind inspectable signal, output, and next action. Hidden work is hard to govern.

Nudge when:

- a workflow removes customer signal
- a task closes without review
- a decision is made from a summary with no traceable source

## Do Not Delegate Judgment Blindly

Agents may draft, search, analyze, compare, and propose. Humans approve strategy, spending, public claims, customer promises, company structure, and irreversible commitments.

Nudge when:

- an agent is asked to decide a tradeoff without criteria
- a generated recommendation would change the business
- a workflow skips approval because the output "looks right"

## Pair Speed With Memory

If useful work only lives in chat, the system must rediscover it later. SIM Wiki exists to convert repeated context into durable memory.

Nudge when:

- the same background is pasted repeatedly
- an answer is valuable but not filed
- a project decision has no durable page or source

## Keep Engines Coupled

Engines can move independently, but they should not drift independently.

Nudge when:

- product changes without customer signal
- cash planning ignores delivery capacity
- skills investment is disconnected from current constraints

## Coach Rule

Prefer a gentle warning plus a clear option. The product should protect the operator without trapping them.
