# SIM Drivers

Drivers coordinate the engines. They are not departments; they are recurring forces that keep the company adaptive, bounded, relational, and coherent.

## Innovation

Innovation changes what the system tries next.

Healthy signs:

- experiments are connected to clear hypotheses
- new work is small enough to learn from
- novelty serves the venture's current constraint

## Governance

Governance decides what the system is allowed to do.

Healthy signs:

- approval boundaries are explicit
- agents can draft and research, but humans own judgment
- spending, public claims, customer promises, and structure changes require review

## Interaction

Interaction governs how the system exchanges signal internally and externally.

Healthy signs:

- customer signal reaches product and cash decisions
- agents leave artifacts that humans can inspect
- handoffs preserve context and next action

## Culture

Culture governs what the system repeats, rewards, and refuses.

Healthy signs:

- learning is captured into durable memory
- operators can challenge agent output without friction
- the system values coherence over speed alone

## Coach Rule

When a user changes a workflow, identify which driver is strengthened or weakened. A change that speeds one driver while weakening another may need an approval nudge.
